## Learning Path

A practical progression is:

1. Start with **Clover Lab: Network Setup Sprint** to understand the authorized lab environment.
2. Build network-discovery skills with **Clover Recon: Nmap First Steps** and **Netdiscover: Network Scout**.
3. Continue with **Clover Cache: Anonymous FTP** and **FTP Shadows: Anonymous Recon** for FTP investigation.
4. Practice combined application and service reconnaissance with **Clover Lab: Web & FTP Recon**.
5. Explore **Clover Decode: Bits, Bytes & Burrows** and **Clover File Trail** for data-analysis practice.
6. Progress through the Horcrux-themed enumeration challenges.
7. Finish with **Aragog Root Hunt** and document the security concepts demonstrated throughout the collection.

## How to Use the Labs

1. Select a challenge from the index.
2. Read the lab instructions and identify its learning objective.
3. Work only inside the authorized CTF environment.
4. Record network observations, service information, files, and relevant evidence.
5. Explain the security significance of each discovery.
6. Document defensive considerations where appropriate.
7. Keep a personal methodology log for future CTF and penetration-testing practice.

Only perform security testing against systems where you have explicit authorization.
